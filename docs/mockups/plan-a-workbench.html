# 云工作空间

示例说明文档。
ws-alpha-1 · ready · rev 7 deepseek/deepseek-v4.1-flash 完全权限 会话由外壳渲染 · 文件与预览由插件注册的 pane 提供
  • 1外壳左栏：DSH 自己的会话/工作区浏览。我们的「云工作空间」入口也在这里（图上蓝色那行），点开即进入本屏。
  • 2会话区 = 外壳的 Chat view：消息、推理、工具卡、审批、计划、流式、输入器全部是原生的 —— 这就是「功能完全一致」。
  • 3右栏是官方 Sidebar 的停靠列：我们注册的 pane（文件树 / 预览 / 运行）。注意它贴靠在右侧、带宽度拖拽条，不是浮层。
  • 4预览 pane：与文件树同栏，用官方原语渲染（语言表头、行号、复制、Markdown 排版）。

采用 A 之前全屏浮层盖住外壳：会话是我们自建的面板（样式与交互都与原生不同）， 官方右栏浮在浮层之上，看起来像"原生界面盖住了插件"。
采用 A 之后没有浮层：会话由外壳渲染、右栏是同一界面的停靠列， 三块在同一条水平线上共享宽度，谁也不盖谁。
代价（需要你确认）：左栏是外壳的浏览（我们的"工程目录/文件列表"移到右栏）；插件原有的 工作空间列表、生命周期、运行与审批等产品面，需要另找落点（右栏的一个 pane，或左栏入口下的页面）。
